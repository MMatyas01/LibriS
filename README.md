# LibriS

A Flutter mobile application for managing personal book collections, recognizing books from cover photos, and connecting readers through a shared book database.

Detailed project documentation, architecture overview, database schema, and screen-by-screen breakdowns are available here:

## 🚀 Getting Started

To run this project locally:

1. Clone the repository.
2. Run `flutter pub get` to install dependencies.
3. Ensure you have the `firebase_options.dart` configured for your environment.
4. Run the app using `flutter run`.
